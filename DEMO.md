## 🎯 Quick Demo Guide

### Step 1: Open Demo
Click the demo link above to open the application in your browser.

### Step 2: Connect Device
1. Click the **"Disconnected"** badge in top-right corner
2. Select your Revopoint DAT from the device list
3. Click **"Pair"**

### Step 3: Try Features

#### Basic Controls
- Use arrow buttons to rotate left/right
- Use +/- buttons to tilt up/down
- Try keyboard shortcuts: W/A/S/D

#### Multi-Stage Rotation (NEW!)
1. Scroll to "Multi-Stage Rotation" section
2. Click **"Load Preset"** to see example
3. Click **"Start Sequence"** to run
4. Watch real-time progress!

## 💡 Demo Tips

### For Best Experience:
1. **Use Chrome or Edge** - best Web Bluetooth support
2. **Enable Bluetooth** on your device first
3. **Stay close** to turntable (within 10 meters)
4. **Start with preset** in Multi-Stage mode
5. **Try keyboard shortcuts** - faster control!

### Common Demo Actions:
- 🔄 **Quick Test**: Click "Load Preset" → "Start Sequence"
- 🎮 **Manual Control**: Use WASD keys for instant rotation
- 📊 **Progress View**: Watch real-time angle updates
- 🎨 **UI Exploration**: Hover over buttons for tooltips

## 🔧 Testing the Demo

### Things to Try:

#### 1. Connection Test
- Click status badge in top-right
- See if your turntable appears
- Test connect/disconnect

#### 2. Basic Controls
- Rotate 90° left and right
- Tilt to -20° and +20°
- Use "Zero" buttons to reset

#### 3. Multi-Stage Demo
- Load the preset (3 stages)
- Start sequence
- Watch progress bar
- Try emergency stop

#### 4. Keyboard Control
- Press `A` - rotate left 1°
- Press `D` - rotate right 1°
- Press `W` - tilt up 1°
- Press `S` - tilt down 1°

#### 5. Responsive Design
- Resize browser window
- Try on tablet/mobile
- Test touch controls

## 📞 Demo Support
