## Original Work

This enhanced version is built upon the excellent foundation created by the open-source community.

### Primary Contributors

#### **[eXplOiD1](https://github.com/eXplOiD1)**
- **Repository**: [Revopoint-Dual-Axis-Turntable-webbased-Controller](https://github.com/eXplOiD1/Revopoint-Dual-Axis-Turntable-webbased-Controller/)
- **Contribution**: Created the original web-based controller using Web Bluetooth API
- **Key Features**: 
  - Bluetooth connectivity implementation
  - Basic rotation and tilt controls
  - Keyboard shortcuts (WASD)
  - Stepped rotation mode
  - Auto rotation cycle

#### **[SphaeroX](https://github.com/SphaeroX)**
- **Contribution**: Created the base system that inspired eXplOiD1's work
- **Impact**: Established the foundation for web-based turntable control

## Enhanced Version Features

Building upon the original work, this enhanced version adds:

### Version 2.2 (Current)
- ✨ Click-to-connect status badge
- 🐛 Improved Bluetooth stability with mutex protection
- 🐛 Enhanced error handling and recovery

### Version 2.1
- ✨ Multi-Stage Rotation mode with custom sequences
- ✨ Visual progress tracking
- 🎨 Dynamic stage management UI

### Version 2.0
- 🎨 Complete UI redesign with modern gradient theme
- ✨ Smooth animations and transitions
- 💡 Interactive tooltips
- 📱 Responsive design for mobile devices
- 🌙 Enhanced dark theme
- 📚 Comprehensive documentation
